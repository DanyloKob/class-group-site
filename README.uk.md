# L-23 LIFE: вебзастосунок для класної групи

[English](README.md)

Сайт однієї класної групи, зроблений насамперед під телефон: розклад, чергові, ДЗ, завдання й
збори коштів, новини та спільні фото в одному місці замість групового чату, де все важливе
відпливає за хвилину. Вхід через Telegram-бота: учасник ділиться своїм контактом, номер
звіряється з тим, що вніс адмін, і жодного пароля пам'ятати не треба. Інтерфейс українською.

Зроблено під один клас на ~20-40 людей, тож модель даних повторює його реальний розпорядок, а не
намагається бути загальною шкільною платформою.

## Що вміє

- **Розклад.** Перегляд по днях зі смугою днів тижня й переходом через календар. Чисельник і
  знаменник, дві підгрупи (A і B) зі спільними парами на всю ширину, до чотирьох пар на день.
  Повторювані пари й чергування вносяться один раз на пару «день тижня + тип тижня», з
  можливістю перевизначити конкретну дату.
- **Чергові.** Чергування в їдальні й біля дошки як дані, а не фото паперового аркуша.
- **ДЗ.** У кожної пари є панель домашнього завдання: будь-хто з учасників додає записи,
  редагує й видаляє свої; записи сортуються за вподобайками.
- **Завдання.** Звичайні справи, які учасник позначає виконаними сам, і збори коштів, де статус
  оплати ставить лише той, хто збирає гроші.
- **Новини.** Оголошення від адмінів із вподобайками й закріпленням, найближча подія вгорі.
- **Спогади.** Стрічка тексту й фото (PNG/JPG, перевірка за сигнатурою файлу) для тих, кому
  дозволено публікувати.
- **Акаунти й ролі.** Суперадмін, адмін (староста) з окремими дозволами та учасник. Суперадмін
  реєструє учасників за номером телефону й ім'ям. Аватар підтягується з Telegram, є світла й
  темна тема, акцентний колір, журнал створених і видалених записів та web push-сповіщення
  (застосунок встановлюється як PWA, без чого iOS не дає push).

Інтерфейс навмисно лишається колонкою ширини телефона на будь-якому екрані.

## Стек

Next.js 16 (App Router) + TypeScript, React 19, PostgreSQL + Prisma 7, Tailwind CSS 4, Framer
Motion, Vaul, grammY (Telegram-бот), web-push, sharp, zod.

## Локальний запуск

1. Підняти Postgres (один раз):
   ```bash
   podman run -d --name classgroup-postgres -p 5432:5432 \
     -e POSTGRES_PASSWORD=devpass -e POSTGRES_DB=classgroup \
     -v classgroup-pgdata:/var/lib/postgresql/data \
     docker.io/library/postgres:16-alpine
   ```
2. `cp .env.example .env` і заповнити значення. Пояснення до кожної змінної є в самому
   `.env.example`. Токен бота можна лишити порожнім, поки не створите бота через @BotFather:
   dev-логін і решта застосунку працюють і без нього.
3. Встановити залежності, створити схему й тестових користувачів:
   ```bash
   npm install
   npx prisma migrate dev --config prisma7.config.ts
   npx prisma generate --config prisma7.config.ts
   npx prisma db seed --config prisma7.config.ts
   ```
4. `npm run dev` піднімає одразу 3 порти й процес бота:
   - `localhost:8080`: суперадмін (dev-автовхід)
   - `localhost:8090`: староста (dev-автовхід)
   - `localhost:8091`: гість (екран входу з dev-вибором тестового учасника)

   `npm run dev:one` піднімає лише один сервер на порту 3000.

Структура проєкту описана в [README.md](README.md#project-structure), а користувачі, ролі й
принципи продукту в `PRODUCT.md`.
